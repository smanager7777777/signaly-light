# signaly-light

Управление адресной лентой (WS2812B) через контроллер с прошивкой WLED — из Chrome, без установки программ.

Этап 1: подключение, вкл/выкл, яркость (20 / 100 / 255 шагов), цвет (круг, HEX, избранное), белый от холодного к тёплому.

## Файлы
- `light.htm` — страница.
- `wled.js` — модуль обмена с контроллером (JSON API WLED) и перевода цветов, без интерфейса; переносится в другое приложение целиком.
- `wled-mock.js` — заглушка контроллера: `light.htm?mock` работает без железа.
- `tests/` — `node tests/unit.js` (модуль), `node tests/ui-smoke.mjs [Chrome]` (страница в Chrome на заглушке).

## Как открыть
**Основной способ — страница на самом контроллере.** Открыть `http://<IP контроллера>/edit`, загрузить `light.htm` и `wled.js` (имена не менять; не называть страницу `index.htm` — она заменит родной интерфейс WLED). Дальше с любого телефона или компьютера в той же Wi-Fi: `http://<IP>/light.htm`. Адрес подставится сам.

**Запасной (Windows):** скачать архив релиза, распаковать в одну папку, открыть `light.htm` двойным щелчком в Chrome, ввести IP или нажать «Найти в сети». Если Chrome спросит про доступ к устройствам локальной сети — разрешить.

**GitHub Pages не подходит:** страница по https не может обращаться к контроллеру по http (Chrome блокирует смешанное содержимое).
